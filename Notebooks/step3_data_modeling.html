Using Predictive Analytics to Identify Drivers of High-Performing Instagram Reels¶

By: Tori Miller¶

Problem Statement¶

Audience engagement with Instagram Reels varies widely, even within the same creator’s content. Because creators differ in audience size and baseline performance, raw engagement metrics alone are not reliable for comparison.

This analysis aims to identify which content characteristics are associated with a Reel achieving above-baseline performance, defined by the binary variable performance_bucket. This creator-relative measure allows performance to be evaluated within the context of each creator’s typical output.

The goal is to determine whether features such as reel structure, hook type, and presentation elements are associated with higher-performing content.

Modeling Approaches¶

Three classification models were initially tested: logistic regression, a classification tree, and k-nearest neighbors (k-NN). These were selected because the target variable is binary and the dataset consists primarily of categorical features encoded as binary indicators.

For the final analysis, logistic regression and k-NN are emphasized because they provided the strongest basis for comparison. The classification tree is included as an exploratory model to assess nonlinear relationships, but its predictive performance was weaker.

Hyperparameter Tuning¶

Hyperparameter tuning was conducted for logistic regression and k-nearest neighbors using a manual grid search approach.

Logistic Regression¶

The following parameters were tuned:

  • penalty (l1 and l2)
  • C (10, 1, 0.1)

These parameters control the type and strength of regularization. Different combinations were tested to evaluate how regularization affects model performance. The final logistic regression settings were selected based on the highest F1 score, since the dataset is imbalanced and the goal is to correctly identify high-performing reels.

k-Nearest Neighbors (k-NN)¶

The following parameter was tuned:

  • n_neighbors (k values from 1 to 19)

This parameter controls how many neighboring data points are used to classify each observation. Different values of k were tested to evaluate how model performance changes with varying levels of sensitivity to local patterns.

The initial model selected k based on accuracy, which resulted in k = 17. However, accuracy alone was not appropriate due to class imbalance, as the model could achieve reasonable accuracy by favoring the majority class.

To address this, k was re-evaluated using F1 score, which balances precision and recall for the high-performing class. The final value of k = 5 was selected based on the highest F1 score, indicating better performance in identifying high-performing reels.

Model Comparison¶

Overall, k-nearest neighbors (k-NN) performed better than logistic regression, while the classification tree performed worst and is not recommended as a final model.

This conclusion is supported by the evaluation metrics. The tuned logistic regression model achieved an F1 score of 0.32 for the high-performing class, indicating a slightly better balance between precision and recall for that class. However, k-NN achieved higher overall accuracy (0.62 vs. 0.42) and higher precision (0.33 vs. 0.25), indicating stronger overall classification performance. While logistic regression identified more high-performing reels (higher recall), it also produced more incorrect predictions, reducing its overall effectiveness.

Because the goal of this analysis is to identify high-performing reels while still maintaining reasonable overall classification performance, k-NN provides the stronger final model. It offers a better balance between correctly identifying high-performing reels and avoiding excessive misclassification of baseline reels.

The results also suggest that content features alone provide only modest predictive power, regardless of model choice. Even the best-performing model struggled to consistently identify high-performing reels, indicating that external factors such as timing, audience behavior, and algorithmic reach likely play a significant role in Reel performance.
